## Update rules

1. Add a row only after a real person voluntarily begins the test.
2. Include stopped and failed attempts instead of reporting only successes.
3. Use an anonymous test ID unless the participant chose to open a public Issue.
4. Do not quote or summarize private feedback without permission.
5. Link confirmed problems to a public Issue only when disclosure is safe and permitted.
6. Recalculate the aggregate from the ledger; never infer users from stars or downloads.
