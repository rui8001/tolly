## Draft application answers

Refresh all facts before copying these drafts. Each draft is intentionally concise and does not claim broad adoption.

### Repository qualification

Tolly is a local-first Windows app that helps developers understand verifiable usage from 20 AI coding tools without uploading conversations to an analytics service. It ships tested NSIS/MSI releases, uses read-only collectors and explicit privacy boundaries, and labels estimates instead of presenting them as bills or account balances. I am its primary maintainer and use public CI, Issues, pull requests, and releases to maintain it.

### Planned API-credit use

I would use credits only for Tolly's open-source maintenance: privacy-focused pull-request review, generating and evaluating synthetic collector fixtures, triaging reproducible Issues, checking documentation against code, and verifying release notes. Credits would not process users' private logs or fund unrelated personal projects.

### Additional context

Tolly fills a Windows gap for local AI coding usage transparency and supports tools used across different developer communities. The project is new, so I am reporting adoption conservatively and publishing a zero-based real-user trial ledger. I also maintain reusable Codex Skills for teaching-video and media workflows, but Tolly is the primary application repository.
