# Tolly v1.1.0

Tolly 1.1.0 重点改进了额度准确性和 Windows 托盘体验。余额只采用服务商明确提供的数据，不再允许手工填写，也不会根据 Token 消耗猜测。

![Tolly 1.1.0 用量总览](https://raw.githubusercontent.com/rui8001/tolly/v1.1.0/docs/assets/v1.1.0/overview.png)

## 主要更新

- Codex 显示与设置页一致的账户“通用使用限额”，自动读取真实周余额和重置时间；Spark 等模型专属额度不会混入。
- 修正 Codex 缓存 Token 的统计口径，避免输入量、成本和命中率重复计算。
- WorkBuddy 显示当日积分消耗；千问办公和豆包工作仅在所选周期确有用量时显示。
- 卡片右上区域用于周余额、剩余积分或今日积分消耗，并加入直观进度条。
- 缓存命中统一显示为“命中”，同一工具的统计图标统一使用其品牌色。
- 修复托盘小窗越过屏幕工作区、圆角不一致以及内容无法向下滚动的问题。
- 设置页聚焦卡片显隐、刷新频率和必要的隐私开关，移除手工额度配置。

![Tolly 1.1.0 设置页](https://raw.githubusercontent.com/rui8001/tolly/v1.1.0/docs/assets/v1.1.0/settings.png)

## 升级方式

下载 Release 中的 NSIS `.exe` 或 MSI `.msi` 安装包，直接覆盖安装 1.0.0 即可。安装后原有卡片显示和刷新设置会继续保留。

安装包目前没有 Authenticode 代码签名，因此 Windows 可能显示“未知发布者”。请从本仓库 Release 下载，并使用随附的 `SHA256SUMS.txt` 核对文件完整性。

## 隐私说明

Token 用量继续在本机处理。Codex 余额通过已安装 Codex 的只读本机接口获取，并复用 Codex 自己的登录状态；Tolly 不读取认证文件。千问办公额度查询仍为可选功能。

## 已知限制

- 暂未启用自动更新，升级需要手动下载安装包。
- 安装包暂未签名，首次安装或升级可能触发 Windows 提示。
- 不同工具的日志格式会随上游版本变化；无法确认的数据会隐藏，而不是估算余额。
