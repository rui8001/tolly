# Tolly v1.2.0

Tolly 1.2.0 重点改进了余额状态表达、豆包工作统计和项目用量准确性。所有统计仍然默认在本机完成，不上传对话内容。

![Tolly 1.2.0 用量总览](https://raw.githubusercontent.com/rui8001/tolly/v1.2.0/docs/assets/v1.2.0/overview.png)

## 本次更新

- **四档渐变余额条**：剩余比例不低于 50% 时沿用工具主色；30%–49% 显示黄色，10%–29% 显示橙色，低于 10% 显示红色。
- **豆包工作本地调用统计**：读取桌面客户端 SDK 日志中可验证的 `chat/completion` 请求，按今日、昨日、本周等周期显示调用次数。
- **项目归属更准确**：Codex、千问办公和 WorkBuddy 优先使用日志记录的真实工作目录，不再把日期目录或会话目录误当项目。
- **项目页支持周期切换**：项目内容与顶部的今日、本周、本月等筛选同步，只显示当前周期真正有用量的项目。
- **零成本项目也有占比**：没有价格或成本为零的本地估算项目，仍可按用量显示项目进度条。

![Tolly 1.2.0 项目用量](https://raw.githubusercontent.com/rui8001/tolly/v1.2.0/docs/assets/v1.2.0/projects.png)

## 统计口径说明

豆包工作当前本地日志没有稳定、可验证的 Token 或剩余积分字段，因此 Tolly 显示的是实际发起的本地对话请求次数，并明确标注“不等同于 Token 或积分”。这避免了用估算值冒充服务商账单。

Codex 周余额继续读取与 Codex 设置页一致的账户通用使用限额，不使用模型专属限额，也不会根据本地 Token 消耗反推余额。

## 下载

- `Tolly_1.2.0_x64-setup.exe`：推荐普通用户使用，可覆盖安装 1.1.0。
- `Tolly_1.2.0_x64_en-US.msi`：适合 MSI 部署。
- `SHA256SUMS.txt`：两个安装包的 SHA-256 校验值。

安装包目前未使用 Windows Authenticode 代码签名，系统可能显示“未知发布者”。请只从本仓库 Release 下载，并核对 `SHA256SUMS.txt`。
