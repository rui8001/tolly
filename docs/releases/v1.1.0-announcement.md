# Tolly 1.1.0 发布介绍

## 一句话介绍

Tolly 1.1.0 让 Windows 上的 AI 编程用量统计更准确、更紧凑：Codex 显示真实通用周额度，WorkBuddy 显示今日积分消耗，托盘窗口的定位、圆角和滚动体验也得到完善。

## GitHub 简短介绍

Tolly 1.1.0 即将发布。本次更新重点解决额度显示的可信度：Codex 直接读取账户通用使用限额，不再把 Spark 等模型专属额度当成周余额；缓存 Token、成本和命中率的计算口径也已修正。同时加入 WorkBuddy 今日积分消耗、按周期自动显隐工具卡片、余额进度条，以及更贴合 Windows 托盘的窗口定位、圆角和滚动条。

项目继续保持本地优先、开放源码。无法从服务商明确确认的数据会隐藏，而不会要求用户手工填写或根据 Token 消耗推算。

## 更新摘要

- 真实 Codex 通用周额度和重置时间
- 正确的 Codex 缓存、成本和命中率统计
- WorkBuddy 今日积分消耗
- 千问办公、豆包工作按实际用量显隐
- 余额进度条与统一工具色
- 修复越界、圆角和滚动问题
- 简化设置页，移除手工余额

下载后请使用 Release 附带的 `SHA256SUMS.txt` 校验安装包。当前安装包未进行 Authenticode 签名，Windows 可能显示“未知发布者”。
